# Tools guidance

- Keep NetCDF reading, file/time selection, height-series collection, plotting, style application, and saving here.
- Do not add domain-specific flag policy to tools.
- Resolve config paths in the configuration layer and accept resolved paths here.
- Preserve numeric height sorting, darkest-blue lowest height, outside legends, and explicit local-time labels.
- Public interfaces must remain snake_case; no legacy wrappers.
